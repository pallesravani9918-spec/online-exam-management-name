# Online Exam Management System

## Project Description

The Online Exam Management System is a web-based application developed using Python Flask, HTML, CSS, and SQLite. It allows students to register, log in, attend an online exam, submit answers, and view their results.

## Technologies Used

* Python
* Flask
* HTML
* CSS
* SQLite
* VS Code

## Features

* Student Registration
* Student Login
* Online Examination
* Automatic Score Calculation
* Result Display
* View Exam Results
* Simple and User-Friendly Interface

## Project Structure

* `app.py` - Flask backend application
* `index.html` - Home page
* `register.html` - Student registration page
* `login.html` - Student login page
* `exam.html` - Online exam page
* `result.html` - Result page
* `results.html` - Results page
* `style.css` - Website styling
* `image.png` - Project image

## How to Run

1. Install Python.
2. Install Flask using:

```bash
pip install flask
```

3. Open the project folder in VS Code.
4. Run:

```bash
python app.py
```

5. Open the localhost URL shown in the terminal in your browser.

## Objective

The main objective of this project is to provide a simple online platform where students can take examinations and receive their results automatically.
